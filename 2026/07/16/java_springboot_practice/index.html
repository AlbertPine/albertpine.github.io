三、第一课：启动类 — 整个后端的”电源键”

先看整个后端最核心的文件 StudyRoomApplication.java：

只有 7 行代码，它就是后端的入口。

@SpringBootApplication 是一个注解，告诉 Spring Boot：”我是启动类，请帮我自动装配一切”。它干了三件事：自动配置、自动扫描代码、允许定义额外配置。

注解（Annotation）：以 @ 开头，给代码贴”标签”。你写注解，框架读到后自动做对应的事。比如 @RestController 表示”这个类处理 HTTP 请求”，@NotBlank 表示”这个字段不能为空”。

SpringApplication.run(...) 一行启动整个应用：启动内嵌 Tomcat、加载配置、扫描所有组件、连接数据库。

Tomcat：一个 Web 容器。浏览器发 HTTP 请求 → Tomcat 接收 → 转给 Spring 的 Controller → 处理完 → Tomcat 返回结果。传统部署需要单独安装，Spring Boot 内嵌了 Tomcat，不用额外安装。

五、第三课：Controller — 怎么接收请求

注解 干嘛的
@RestController 这个类处理 RESTful 请求，返回值自动转 JSON
@RequestMapping("/auth") 这个类下所有接口 URL 前缀都是 /auth
@PostMapping("/register") 处理 POST /auth/register 请求
@RequestBody 把请求的 JSON 自动转成 Java 对象
@Valid 触发校验（检查学号纯数字？密码非空？）

数据怎么流动？

Controller 的职责：只负责”接待”——接收请求、参数校验、调用 Service、返回结果。不写业务逻辑，不写 SQL。

六、第四课：Service — 业务逻辑的核心

Controller 只是前台，真正干活的是 Service：

关键概念：

  • @Service：告诉 Spring “这是一个 Service Bean，帮我管理”。

  • @Transactional（事务）：如果操作数据库中途出错，自动回滚，不会出现”数据插了一半”的情况。

  • LambdaQueryWrapper：MyBatis-Plus 提供的查询构造器，用 Lambda 表达式写查询条件，不用写 SQL：

  • passwordEncoder.encode()：BCrypt 加密。数据库存的是密文（如 $2b$10$XzL0b...），即使数据库泄露也拿不到密码。

BCrypt：一种不可逆的密码加密算法。同样的密码每次加密结果不同，只能通过 matches() 方法比对，无法解密。

七、第五课：Mapper + Entity — 操作数据库

Entity 实体类：一个 Java 类对应一张数据库表。

注解 含义
@Data Lombok 自动生成 getter/setter
@TableName("user") 绑定数据库表 user
@TableId(type = IdType.AUTO) 主键自增

Lombok：一个编译期代码生成工具。@Data 自动生成 getter、setter、toString 等方法，不用手写。

Mapper：操作数据库的接口。

继承 BaseMapper 后自动获得：

方法 SQL
insert(user) INSERT INTO user VALUES (…)
selectOne(wrapper) SELECT * FROM user WHERE …
selectCount(wrapper) SELECT COUNT(*) FROM user WHERE …
updateById(user) UPDATE user SET … WHERE id = ?

MyBatis-Plus：对 MyBatis 的增强。继承 BaseMapper 后不用写一行 SQL 就能完成增删改查。

八、三层架构总结

层 职责 不该做什么 核心注解
Controller 接收请求、校验参数、返回结果 不写业务逻辑、不碰数据库 @RestController
Service 业务逻辑、校验、加密、事务 不直接接收 HTTP 请求 @Service
Mapper 执行数据库操作 不写业务逻辑 @Mapper

每层只做自己分内的事，这就是分层架构的核心思想。

九、第六课：JWT — 登录后怎么保持登录状态

HTTP 是无状态的：每次请求相互独立，服务器不知道两次请求来自同一个人。

JWT（JSON Web Token）：登录令牌，服务器签发一个签名 token 给客户端，客户端每次请求带上 token，服务器验签确认身份。就像进图书馆刷学生卡。

十、第七课：前端路由 — 页面怎么跳转

前端是 SPA（单页面应用）：只加载一个 HTML，所有”页面切换”实质是 JS 动态替换内容，不刷新整页。

SPA（Single Page Application）：浏览器只加载一个 HTML 页面，切换页面时用 JS 替换内容区域，体验流畅。缺点是首屏加载慢，对 SEO 不友好。

Axios：前端 HTTP 请求库，类似 Java 的 HttpClient。支持拦截器（请求/响应前自动处理），本项目用它统一处理 token 携带和错误提示。

Pinia：Vue 3 的状态管理库。本项目用它存储 token 和用户信息，登录后其他组件都能读取。

名词 一句话解释
Spring Boot Java 后端框架，内嵌 Tomcat，自动配置
Gradle 构建工具，管理 Maven 依赖
MyBatis-Plus 增强版 MyBatis，不需写 SQL 就能操作数据库

Pinia Vue 3 的状态管理，存 token、用户信息
Axios 前端发 HTTP 请求的库

JWT 登录令牌，三段 Base64，防篡改
